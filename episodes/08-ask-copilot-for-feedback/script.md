# Episode 8 — Ask Copilot for Feedback

## Narration script (Aria)

Here is a prompt most people never think to type: ask Copilot to push back. Microsoft lists "ask for feedback" as one of its core prompting habits, and it changes the relationship. Before a big request, try, "What questions do you have for me before you start?" Copilot will surface the gaps you forgot to fill: the deadline you did not mention, the audience you never named. It is mildly annoying and extremely useful. I also use it on finished work. I paste a draft and ask, "What would make this stronger?" Last month it read my project update and pointed out that I had promised a date in paragraph one and contradicted it in paragraph four. It was right, worse luck. Copilot is a decent editor because it has no feelings to protect, yours included. Let it ask the questions. Then answer them.
