# Episode 15 — Don't Like It? Run It Again

## Narration script (Aria)

Here is a small fact that surprises people: ask Copilot the same question twice and you will get two different answers. Not a malfunction. That is how it works. So when an answer is close but not right, you have a cheap option before rewriting anything. Run it again. Hit regenerate, or just say, "Give me another version of that." I do this with subject lines and opening paragraphs, the parts where wording matters most. Three versions take a minute, and the best sentence is usually hiding in version two. Sometimes I keep the first half of one and the ending of another, which feels a little like judging a talent show. Fair enough. You are the judge. The point is that the first answer is one draft among many, and the rerun button is the fastest editor you own.
