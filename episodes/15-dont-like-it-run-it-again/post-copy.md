Mary Anne Minute — Don't Like It? Run It Again

Ask Copilot the same question twice and you will get two different answers. Not a malfunction. That is how it works.

So when an answer is close but not right, run it again before you rewrite anything. Hit regenerate, or say "Give me another version of that," and compare. I do this with subject lines and opening paragraphs, where wording matters most.

Three versions take a minute, and the best sentence is usually hiding in version two. First answers are drafts. Sometimes the second draft is the keeper.
