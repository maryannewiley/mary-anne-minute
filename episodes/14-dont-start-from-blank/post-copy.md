Mary Anne Minute — Don't Start from Blank

The blank prompt box has ended more good intentions than any meeting ever called.

You do not always have to write the prompt. Microsoft's Copilot Prompt Gallery is a library of prompts that already work, organized by job and task. Find one close, run it, adjust a word or two, and save your best ones like recipes.

Somebody in that gallery has already solved the prompt you are staring at. Go borrow their homework. It is allowed here.
