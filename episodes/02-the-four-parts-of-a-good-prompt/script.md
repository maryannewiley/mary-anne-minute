# Episode 2 — The Four Parts of a Good Prompt

## Narration script (Aria)

Here's a secret about Copilot: it can only work with what you hand it. When an answer comes back thin or off target, the prompt usually left something out. Microsoft teaches that a good prompt has up to four parts. Start with the goal: what you want. Then add context: why you need it and who's involved. Point to a source: the file or report it should work from. And finish with expectations: how you want it back. Only the goal is required, but the other three are where the quality lives. Say I'm writing a project update. Instead of "write a status summary," I try: "Using the attached status report, summarize our progress for leadership. Highlight milestones, risks, and next steps in five bullet points." Same tool, same minute of typing. The answer is not even close. Copilot cannot read your mind, no matter how clearly you think at it. Four parts. That's the whole trick.
