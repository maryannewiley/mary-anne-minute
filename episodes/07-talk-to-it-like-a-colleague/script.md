# Episode 7 — Talk to It Like a Colleague

## Narration script (Aria)

Quick question: how do you talk to Copilot? If you write to it like a search engine, three keywords and a prayer, try something else. Microsoft's advice is to keep it conversational. Frame the prompt like you are talking to a colleague. Full sentences. Plain words. The background you would give a person. "I am putting together the agenda for Thursday's planning meeting. We need thirty minutes on the budget and fifteen on staffing. Draft it like last week's, but swap in the new topics." That works better than "meeting agenda budget staffing," because it sounds like a request, not a ransom note. And when the answer is close but not right, respond like a colleague too: "Good start. Now make the second point stronger." Talk to it like someone on your team, and it starts answering like one.
