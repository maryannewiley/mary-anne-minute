# Episode 1 — Don't Accept the First Answer

## Narration script (Aria)

P1: "Here's something I wish someone had told me when I first started using Copilot: the first answer it gives you is not the finished product. It's a starting point."

P2: "Think of it as a conversation with a colleague, because that's honestly how Copilot works best. If the answer comes back too long, just say so — make it shorter. If it sounds stiff, ask it to make it more conversational. If there's a list of action items buried in a paragraph, ask it to put them in a table, where you can actually see them. And if the piece is headed upstairs, ask it to rewrite it for leadership."

P3: "One more, and this is the one I never skip. Before you send anything on, ask Copilot to show you the links to the sources it used. It takes ten seconds, and it's how you know the answer deserves your name on it."

P4: "So don't accept the first answer. Talk back to it. That's where the good work is."
