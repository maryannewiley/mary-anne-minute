# Mary Anne Minute

Short, friendly teaching videos that help beginner AI users get better work out of tools like Microsoft Copilot — one practical tip at a time.

Each episode is under about a minute and a quarter: a single tip, explained in plain conversational language, with the episode's key prompts shown on screen as they're taught. The tips teach how to build a good prompt, work the conversation back and forth, use AI for everyday wins like meeting recaps and inbox briefings, and check what comes back before trusting it. Every tip traces to Microsoft's own published Copilot teaching material (Microsoft Learn and Microsoft Support).

**Made by Mary Anne Wiley.** The series began as "Mary Anne Minute" posts for a private workplace AI learning community, and it was built to travel from the start: nothing in the videos is branded — no logos, no company names, no watermarks — and the series name never appears inside a video, only in the post text that introduces it. That makes each episode reusable for general education in other settings.

## How this repo is organized

- **`CATALOG.md`** — the full episode list: number, title, a one-line summary of the tip, and the video filename. Start there.
- **`episodes/`** — one folder per episode, named `NN-slug`. Each folder holds:
  - the episode video (`.mp4`),
  - `script.md` — the narration script, so the teaching is readable and searchable as text,
  - `post-copy.md` — the public post text that introduces the episode, opening with the "Mary Anne Minute" lead-in.
- **`SERIES-BIBLE.md`** — the complete production recipe (voice, colors, presenter, design rules) for making new episodes that match this set.
