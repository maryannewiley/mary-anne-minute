# Episode Catalog

All 16 episodes of the Mary Anne Minute. Each episode is a standalone tip — watch them in any order. Video files live in the matching folder under `episodes/`, alongside the narration script (`script.md`) and post text (`post-copy.md`).

| # | Title | The tip in one line | Video file |
|---|-------|---------------------|------------|
| 1 | Don't Accept the First Answer | Treat the first answer as a draft: push back — shorter, more conversational, action items in a table, rewrite for leadership, and ask for the source links. | dont-accept-the-first-answer-v2.mp4 |
| 2 | The Four Parts of a Good Prompt | A strong prompt has up to four parts — Goal, Context, Source, Expectations — and only the goal is required. | episode-02-four-parts.mp4 |
| 3 | Be Clear and Specific | Vague in, vague out: name the topic, say the purpose, set the length, pick the tone. | episode-03-be-clear-and-specific.mp4 |
| 4 | Point It to the Source | Tell it where to look — reference the file, the emails, or the meeting by name instead of letting it guess. | episode-04-point-it-to-the-source-v2.mp4 |
| 5 | Say How You Want It Back | Name the audience, tone, length, and format before you hit enter, and the answer lands ready to use. | episode-05-say-how-you-want-it-back.mp4 |
| 6 | Show It an Example | It follows a sample better than a description — paste an example and tell it to match the style and format. | episode-06-show-it-an-example.mp4 |
| 7 | Talk to It Like a Colleague | Keep it conversational: full sentences, plain words, the background you'd give a person, and feedback the same way. | episode-07-talk-to-it-like-a-colleague.mp4 |
| 8 | Ask Copilot for Feedback | Ask "What questions do you have for me before you start?" up front, and "What would make this stronger?" after a draft. | episode-08-ask-copilot-for-feedback.mp4 |
| 9 | One Job at a Time | No conflicting instructions and no topic-switching mid-thread — finish one job, and open a fresh chat when the topic changes. | episode-09-one-job-at-a-time.mp4 |
| 10 | Break It Into Steps | Chain small prompts together — summary, then outline, then draft — and steer at every step. | episode-10-break-it-into-steps.mp4 |
| 11 | Write Legibly. Be Polite. | Real sentences with punctuation, and please-and-thank-you, get clearer answers back. | episode-11-write-legibly-be-polite.mp4 |
| 12 | Catch Up in One Prompt | "Recap /meeting" returns the discussion, the decisions, and the action items — including what you owe. | episode-12-catch-up-in-one-prompt-v3.mp4 |
| 13 | Get Your Inbox to Brief You | Ask what's on your radar from last week's email, and flag what's urgent and what's waiting on your reply. | episode-13-inbox-brief.mp4 |
| 14 | Don't Start from Blank | Borrow a proven prompt from the Copilot Prompt Gallery, adjust it to your context, and save your version. | episode-14-dont-start-from-blank.mp4 |
| 15 | Don't Like It? Run It Again | The same prompt can give a different answer — regenerate, compare versions, and keep the best parts. | episode-15-run-it-again.mp4 |
| 16 | Check It Before You Send It | AI content can be wrong: read it like a stranger, second-check names, numbers, and dates, and open the sources before you share. | episode-16-check-it-before-you-send-it-v2.mp4 |
